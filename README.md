
Settings > About phone > tap "Build number" 7 times (unlocks Developer Options)

Settings > System > Developer options > enable "USB debugging"

Plug the phone into the PC via USB

UnZip ADB_Deep_Dive, address bar type "cmd" and in cmd "adb devices"

Accept the "Allow USB debugging?" popup that appears on the phone screen — this step is easy to miss and the tool will fail without it
